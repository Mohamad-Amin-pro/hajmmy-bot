# 🍔 ربات فلافل فروشی حاج ممی

ربات سرگرمی فلافل فروشی برای پیام‌رسان بله

## 🎮 قابلیت‌ها
- بازی کامل با اقتصاد درون‌بازی
- سیستم کلن، دوئل، هدیه
- پیشرفت (سطح، دستاورد، مهارت، پت)
- پنل ادمین حرفه‌ای
- عضویت اجباری
